ZACK QUEST — V3.33 GITHUB LIGHT

1. Dans le dépôt Zack-Quest, crée un dossier nommé : images
2. Envoie TOUS les fichiers contenus dans le dossier images de ce pack dans ce dossier GitHub.
3. Remplace ensuite ton ancien v3.html par le v3.html de ce pack.
4. Ne renomme aucun fichier image.
5. La structure doit être :

Zack-Quest/
  v3.html
  images/
    asset_01...
    asset_02...
    etc.

Cette version ne contient plus les grosses images en Base64 dans le HTML.
Les images restent locales au projet et sont appelées par chemin relatif.
